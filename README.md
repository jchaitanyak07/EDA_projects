# Paisabazaar Banking Fraud Analysis EDA Project

This project focuses on performing Exploratory Data Analysis (EDA) on the Paisabazaaar Banking dataset to understand its structure, aptterns, relationships, and important trends.

The analysis includes data cleaning, handling missing values, statistical summaries, and visualization of important variables.

Different visualization techniques such as histograms, bar plots, countplots and box plots are used to identify patterns, correlations, outliers, and distributions within the dataset.

The main objective of this project is to extract meaningful insights from the data and prepare ot for further analysis or machine learning task.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Steps
- Data loading
- Data understanding
- Data Cleaning
- Data Wrangling
- Data Visualization
